# أوقات قطارات RFR تونس | Next Train Tunis RFR

تطبيق ويب متطور وخفيف (PWA) لعرض ومتابعة مواعيد قطارات السكك الحديدية السريعة RFR والضواحي في تونس الكبرى (الخط A، الخط D، والخط E)، مبني باستخدام **React 19** و **Vite** و **Tailwind CSS**.

---

## 🌟 المميزات الرئيسية
- 🚆 **مواعيد شتاء 2026–2027**: استناداً إلى الجداول الرسمية الصادرة عن الشركة الوطنية للسكك الحديدية التونسية (SNCFT):
  - **الخط D**: تونس ⇄ القباعة والقباعة المدينة ومنوبة وباردو.
  - **الخط E**: تونس ⇄ بوقطفة وسيدي حسين والحرارية والزهور.
  - **الخط A**: تونس ⇄ الرياض وحمام الأنف والزهراء ورادس ومقرين.
- ⏱️ **عداد تنازلي فوري**: يعرض الوقت المتبقي لانطلاق القطار القادم بالدقائق والثواني.
- 🔄 **تخطيط التنقل بين الخطوط (Interline Transfer)**: دعم التنقل بين الخطوط المختلفة عبر محطة تونس المركزية الموحّدة.
- 📅 **حساب دقيق لأيام التشغيل**: اعتماد تاريخ الانطلاق الفعلي للرحلات (الرموز: `-` كل الأيام، `A` كل الأيام عدا الأحد، `B` الأحد فقط، `C` الاثنين–الجمعة فقط، `D` الأحد والاثنين فقط) ودعم الانتقال بعد منتصف الليل.
- 🕒 **توقيت تونس الفعلي (Africa/Tunis)** عبر `Intl.DateTimeFormat` + إمكانية محاكاة أي توقيت وتاريخ لاختبار الجداول.
- 📶 **دعم كامل للعمل دون اتصال (PWA / Offline)**: تثبيت التطبيق على الشاشة الرئيسية للهواتف وأجهزة الكمبيوتر مع تخزين محلي كامل للجداول.
- 🗺️ **مخطط شبكة تفاعلي**: يوضح مسار الخطوط الثلاثة ومحطة الربط تونس - ساحة برشلونة.
- 🎫 **حاسبة الأسعار والاشتراكات**: لحساب أثمان التذاكر والاشتراكات المدرسية والجامعية والشهرية.
- 📑 **عرض وطباعة الملصقات الرسمية**: إمكانية استعراض جداول المواعيد الأصلية وطباعتها.
- 🌐 **دعم ثلاث لغات**: العربية (افتراضي RTL)، الفرنسية، والإنجليزية.

## 📱 تفعيل وبناء تطبيق Android APK عبر GitHub Actions

المشروع مزوّد ببيئة **Capacitor Android** كاملة داخل مجلد `android/` مع سير عمل آلي **GitHub Actions** في `.github/workflows/build-apk.yml`.

### خطوات الحصول على ملف الـ APK:
1. ارفع المشروع إلى مستودعك على GitHub باستخدام الأوامر أعلاه.
2. اذهب إلى تبويب **Actions** في مستودعك على GitHub.
3. ستلاحظ بدء مهمة **Build Android APK** تلقائياً.
4. عند اكتمال المهمة، ستجد ملف الـ APK تحت قسم **Artifacts** باسم:
   ```
   Tunis-RFR-Android-APK (app-debug.apk)
   ```
5. **إنشاء Release رسمي مع APK:**
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```
   سيقوم GitHub Actions تلقائياً بإنشاء Release رسمي وإرفاق ملف الـ APK الجاهز لتوزيعه على المستخدمين.
