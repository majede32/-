# أوقات قطارات RFR تونس | Next Train Tunis RFR

تطبيق متطور وحديث لعرض مواعيد قطارات السكك الحديدية السريعة RFR والضواحي في تونس الكبرى (الخط A، الخط D، والخط E)، مبني باستخدام **React 19** و **Vite** و **Tailwind CSS**.

---

## 🌟 المميزات الرئيسية
- 🚆 **مواعيد دقيقة لشتاء 2026–2027**: متوافقة مع جداول الشركة الوطنية للسكك الحديدية التونسية (SNCFT).
  - **الخط D**: تونس ⇄ القباعة والقباعة المدينة ومنوبة وباردو.
  - **الخط E**: تونس ⇄ بوقطفة وسيدي حسين والحرارية والزهور.
  - **الخط A**: تونس ⇄ الرياض وحمام الأنف والزهراء ورادس ومقرين.
- ⏱️ **عداد تنازلي فوري**: يعرض الوقت المتبقي لانطلاق القطار القادم بالدقائق.
- 🕒 **توقيت تونس الفعلي (UTC+1)** + إمكانية محاكاة أي توقيت وتاريخ.
- 🗺️ **مخطط شبكة تفاعلي**: يوضح تقاطع الخطوط الثلاثة في محطة تونس - ساحة برشلونة.
- 🎫 **حاسبة الأسعار والاشتراكات**: لحساب ثمن التذاكر والاشتراكات المدرسية والجامعية والشهرية.
- 📑 **عرض وطباعة الملصقات الرسمية**: إمكانية استعراض جداول المواعيد الأصلية وطباعتها بصيغة PDF.
- 🌐 **دعم كامل للغات**: العربية (افتراضي RTL)، الفرنسية، والإنجليزية.

## 🚀 تشغيل المشروع محلياً (Run Locally)

### المتطلبات
- Node.js (الإصدار 18 أو أحدث)
- npm أو bun

### التثبيت والتشغيل
```bash
# 1. تثبيت الحزم والمكتبات
npm install

# 2. تشغيل خادم التطوير
npm run dev

# 3. بناء المشروع للإنتاج
npm run build
```
